# Dataset Description

This repository supports the research paper **"A Hybrid Framework for Automated Detection of Security Tags in Software Systems."**  
It includes the datasets, source code, and experimental results for **Experiment 1** and **Experiment 2** conducted in the study.

## Repository Contents

- **Experiment_1/**  
  Contains the dataset, preprocessing scripts, implementation code, and output results related to the first experiment.

- **Experiment_2/**  
  Contains the dataset, source code, and evaluation results for the second experiment.

## Purpose

This repository is provided **for educational and replication purposes**, enabling researchers and students to:

- Reproduce the experiments presented in the paper.  
- Validate the findings of the hybrid framework.  
- Explore future extensions and variations of the proposed approach.
